# PTB CosMx 1K — subtype viewer

Six specimens (PTB 21.1, 22.1, 22.3, 24.1, 24.2, 24.3), **1,803,099 cells**, 1,000-gene
CosMx panel. Labels transferred from the 202610 combined PTB snRNA reference in two
rounds: 10 major types, then 60 subtypes within lineage.

Live: https://YiqianGu.github.io/202610_cosmx_1k_PTB_subtype/

Generated by `cosmx_rna_1k/scripts/01_combined_annotation/08_viewer.R` (analysis node
A01). This repo holds the rendered payload only; the analysis, its parameters and its
caveats live in the project tree.

## Read these before quoting anything

1. **This panel resolves subtypes far less well than the 6K companion.** 923 of the 992
   human probes are in the reference, but the **median reference subtype keeps only 26%
   of its marker list** on this panel (6K: 68%); 19 of 57 subtypes keep fewer than 20
   markers. A subtype call here is a best match among 60 options on a thin gene set.
2. **The immediate-early programme is essentially absent** — `EGR1`, `EGR2`,
   `NR4A1/2/3`, `KDM6B`, `FOSB`, `TRAC` are all off-panel. Both populations on the
   **Activation** layer are defined in the reference by exactly that programme, so treat
   that layer as a pointer for inspection, not as a count.
3. **Between-sample composition is confounded with segmentation.** PTB 21.1 and 24.3
   were segmented with `seg_2026`; the other four with `seg_202606`. Median library size
   also ranges 2x across samples.
4. **Immunofluorescence is not uniform.** `CD3` is on five samples but **not PTB 21.1**,
   which carries `CD68` instead. `CD45`/`PanCK`/`Membrane`/`DAPI` are on all six.
5. **The QC floor is deliberately low** (>=20 counts, 95.1% retained) because every
   higher floor preferentially deletes T cells. Sparse cells are flagged on the
   **Transfer confidence** layer rather than removed — filter there.
6. **`Proliferating` absorbs T cells on this panel**: it is 44.2% CD3+ against T cell's
   44.9%, and ranks above T cell on CD45 protein. It is not a proliferation measure.
7. `Mesothelial` claims 15,819 cells from a **31-cell** reference class and `cDC1` is
   called at 2.4x the reference rate — both behave as sinks.

Marker genes: the top 150 (by rank across all labels) are exported, which covers ranks
1-4 of every label. Genes beyond the cut are greyed out in the marker panel.
